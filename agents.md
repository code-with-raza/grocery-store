# Token-Efficient Coding Rules

- Keep responses short and focused.
- Inspect only files relevant to the requested task.
- Search before opening large files.
- Avoid reading the same file repeatedly.
- Do not print entire files, directories, or long command outputs.
- Make the smallest correct code changes.
- Do not refactor unrelated code.
- Run only relevant tests.
- Do not create subagents unless explicitly requested or genuinely necessary.
- Avoid unnecessary planning and progress updates for simple tasks.
- Summarize completed changes and test results in a few bullets.
- Ask before expanding the scope of the task.
